	mes "[神秘女士]";
	mes "如果您計劃前往較冷的地區，我建議您帶一些 ^3355FF耳罩^000000...";
	emotion ET_THINK;
	next;
	mes "[神秘女士]";
	mes "耳罩是我家族的特色產品，我們提供給擁有 ^FF33551 Cursed Ruby^000000、^3311AA1 Headset、^3355FF 200 Feathers^000000 和 ^DDDD005000 Zeny^000000 的客戶。";
	emotion ET_THINK;
	next;
	switch(select("喔？聽起來不錯。:不用了，女士。")) {
	case 1:
		if ((countitem(724) > 0) && (countitem(949) > 199) && (countitem(5001) > 0) && (Zeny > 4999)) {
			mes "[神秘女士]";
			delitem 724,1; //Cardinal_Jewel_
			delitem 949,200; //Feather
			delitem 5001,1; //Headset
			set Zeny,Zeny-5000;

			next;
			mes "[神秘女士]";
			mes "感謝您購買我們的產品。您不會後悔購買我們的耳罩：保證滿意～";

			close;

		mes "[神秘女士]";
		mes "沒關係。";
		mes "我相信我們";
		mes "會再次相遇的。";
		mes "...總有一天。";
		emotion ET_THINK;
